# Independent exhibition pilot procedure

The second real exhibition pilot has not started. Do not treat synthetic fixtures or Chuen Lung regression assets as a pilot.

## Intake materials

- Read-only exhibition photo folder.
- Stable project ID.
- External workspace path.
- Basic public/private and access policy.
- Optional existing COLMAP reconstruction or validated PLY.
- Optional artwork inventory and evidence.

## Pilot sequence

1. Initialize the project and inventory photographs.
2. Run capture preflight and inspect reconstruction readiness.
3. Review the full-hash SfM plan; explicitly authorize fresh SfM only if needed.
4. Validate connected reconstruction and recapture risks.
5. Review the full-hash Spirula training plan; explicitly authorize only the approved run.
6. Evaluate candidate models and select one by evidence.
7. Review artwork inventory and confirm identities from supplied evidence.
8. Generate navigation proposal and inspect boundaries, floor, ceiling, portals, and viewer transform.
9. Human-review and approve navigation.
10. Verify the selected model and current package inputs.
11. Generate the local public website candidate.
12. Review image and artwork rights and access policy.
13. Verify package hashes and privacy separation.
14. Run browser acceptance.
15. Record both Publish Package contents and any separately managed preservation materials.

## Pilot risks

Coverage and image registration, reflective or pale surfaces, unseen artwork, venue permissions, uncertain inferred architecture, portal and accessibility evidence, actual host device authorization, model fidelity, package privacy, and preservation completeness must be assessed on the new venue. Record the pilot as NOT_STARTED until an independent real exhibition dataset has entered this process.
